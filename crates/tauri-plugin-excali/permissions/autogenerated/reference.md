## Default Permission

Every command of the plugin: the open and save dialogs, the headless
export, the allow-listed library fetch and validation. `save` and `export`
write only paths the plugin's own dialogs returned.

#### This default permission set includes the following:

- `allow-open`
- `allow-save`
- `allow-export`
- `allow-library-fetch`
- `allow-validate`

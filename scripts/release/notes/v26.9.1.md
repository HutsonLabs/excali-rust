The first release of excali-rust, a port of Excalidraw to Rust and WebAssembly, numbered by calendar `YY.M.BUILD` (ADR-009).

**Assets**

- `excali-web_26.9.1.tar.gz`: the web runtime as `scripts/web/build.sh` builds it: `excali_editor.js` (the ES module that defines `<excali-editor>`), `excali_editor_bg.wasm`, `excali.css` and `fonts/` (the range-split font files, their licences and `manifest.json`). Built, packed reproducibly and uploaded by `.github/workflows/release.yml` from this tag.
- `SHA256SUMS`: the tarball's SHA-256 in `shasum` format.

Fetch and check both, then unpack into a directory, with `scripts/release/fetch.sh 26.9.1 vendor/excali` (curl, tar and shasum or sha256sum), or by hand: `gh release download v26.9.1 -R HutsonLabs/excali-rust -p 'excali-web_*' -p SHA256SUMS && shasum -a 256 -c SHA256SUMS`.

**What it does**

- The `.excalidraw` and `.excalidrawlib` formats: every scene-bearing upstream test fixture and all 232 catalogue libraries round-trip byte for byte against upstream, unknown fields kept (M1).
- rough.js and shape construction match upstream's `generateElementShape` on all 684 cases of the element type x fill style x roughness x seed matrix (M2); text wrapping, bound text and font measurement pass upstream's tests (M3).
- PNG and SVG export and the `excali` CLI (`cargo install --git https://github.com/HutsonLabs/excali-rust --tag v26.9.1 excali-cli`): SVG export reproduces upstream's snapshots byte for byte, and the CLI renders all 4187 items of the catalogue libraries (M4).
- The editor as a custom element, `<excali-editor>`: all 64 rows of the parity checklist pass in Chromium, first paint under 300 ms and panning 1,000 elements under 16.7 ms a frame, held in CI (M7).
- Tauri v2 hosts: `tauri-plugin-excali = { git = "https://github.com/HutsonLabs/excali-rust", tag = "v26.9.1" }` gives native open, save, export and library import; term.hut vendors the web runtime (M6).

The integration guide (https://hutsonlabs.github.io/excali-rust/architecture/integration/) walks a host through both, and was walked step by step in a fresh clone.

Not published to crates.io, npm or any other registry: the crates keep `publish = false` (the crates.io task is deferred by the owner).
